# Content sources

Cuisine descriptions are concise editorial explanations, with links to dish articles. Wikipedia summaries were consulted where available. Each country shows one culinary example, not an official or exclusive national-dish claim. Uninhabited territories do not receive invented dishes.

Images: Wikimedia Commons image metadata (author, image page, reuse license), plus TheMealDB's documented meal-photo API endpoints. Each photo carries its corresponding attribution and source. Images are cached as optimized WebP for stable mobile delivery; the originals remain linked. No generic stock food photo is used as an unrelated dish.

Area: World Bank AG.SRF.TOTL.K2 with year. Canada is overridden using the official Canada.ca conserved-areas territorial definition (9,984,670 km², land and freshwater), excluding marine territory. Different geographical coverage definitions should not be silently mixed.

Audio: original browser-synthesized ambient chords and chime, approved by the user. It has not been replaced during the navigation/cuisine update.
