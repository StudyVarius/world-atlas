# Атлас мира — исходный проект

## Как открыть в VS Code

1. Распакуйте весь архив, сохранив папки.
2. Откройте папку world-atlas через File → Open Folder.
3. Нужен Node.js 18 или новее. В терминале выполните:

```bash
npm start
```

Откройте http://localhost:5173 в браузере. npm install не требуется: npm-зависимостей нет.
Альтернатива: расширение Live Server в VS Code или `python -m http.server 5173`.
Не открывайте index.html двойным щелчком: через file:// браузер блокирует чтение JSON.

## Какие файлы нужны

- index.html — структура сайта.
- app.css — стили, включая телефонную версию.
- app.js — карта, поиск, фильтры, расстояния, часы.
- cuisine.js — блюда, фотографии и подробности.
- audio.js — одобренная музыка, звуки и звёзды.
- stats.js — «Мир в цифрах».
- package.json и server.mjs — локальный запуск.
- JSON-файлы — данные стран, столиц, блюд, площади и населения.
- images/food/ и paris.jpg — изображения.
- d3.js и tz.js — библиотеки, уже включённые в проект.
- CONTENT_SOURCES.md — источники данных и фотографий.

## Почему нет App.tsx

Существующий сайт написан на HTML, CSS и обычном JavaScript. Он не использует React или TypeScript, поэтому App.tsx ему не нужен. app.js — полноценный код приложения. Этот архив сохраняет текущую реализацию без ненужной переработки.

## Телефон

Компьютер и телефон должны быть в одной Wi-Fi сети. Запустите сервер и откройте http://IP-АДРЕС-КОМПЬЮТЕРА:5173 на телефоне. Может потребоваться разрешить порт в межсетевом экране. Для геолокации вне localhost обычно нужен HTTPS; город можно выбрать вручную.

## Сохранение и публикация

Сохраняйте всю папку проекта, а не только HTML: приложение загружает данные и картинки отдельными файлами.
Для статического хостинга нужны HTML, CSS, JS, JSON и изображения с теми же относительными путями. Настройки приватного размещения ChatGPT, Git и учётные данные в архив не включены.
Внешние ссылки и некоторые фотографии требуют интернета. Фотографии пока доступны не для всех блюд.
